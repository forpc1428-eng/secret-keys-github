Good to know

Do I have to click the bookmark on every page?

Yes — bookmarks can't run by themselves. Click it once per page (or after a reload) and all your saved shortcuts and macros come back instantly. For fully automatic, use the extension zip.

Why doesn't it open on some sites?

A few sites (like GitHub, Gmail or X) block outside scripts for security. Those need the extension version.

Are my shortcuts shared between sites?

Each website keeps its own saved data. Use Export on one site and Import on another to copy macros across.

Does it work on my phone?

Mostly yes. Tap “Copy bookmark code”, bookmark any page, then edit that bookmark: name it Secret Keys and paste the code as its address. In Chrome for Android, type “Secret Keys” in the address bar and tap the bookmark to run it. In Safari on iPhone, open it from your bookmarks.

Is it private?

Yes. Everything stays in your own browser. Nothing is sent anywhere.
